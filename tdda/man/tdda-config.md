# "TDDA VERSION" 1 "January 2026" "3.0" "tdda config manual"
## NAME

`tdda config` - Shows config settings

## SYNOPSIS

`tdda config` - Shows current config settings
`tdda config --current` - Shows current config settings
`tdda config --default` - Shows default config settings
`tdda config --file` - Shows config file location and contents.

## DESCRIPTION

Shows configuration information. Use

`-c`, `--current` or `current` for the default configuration
`-d`, `--default` or `default` for the default configuration
`-f`, `--file` or `file` for the configuration file location and contents.

With no argument, it shows the current configuration.

## EXAMPLES

`tdda config`
`tdda config -c`
`tdda config -d`
`tdda config -f`
