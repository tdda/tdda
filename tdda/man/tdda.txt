NAME

  [1mtdda [22m− test‐driven data analysis

SYNOPSIS

  [1mtdda discover      [22mPerform constraint discovery
  [1mtdda verify        [22mVerify data against constraints
  [1mtdda detect        [22mDetect failed constraints on data

  [1mtdda examples      [22mCopy the example data and code
  [1mtdda gentest       [22mGenerate a reference test "automagically"

  [1mtdda diff          [22mCompare two parquet or CSV files
  [1mtdda serial        [22mConvert or view .serial, CSVW,
                     and Frictionless metadata
  [1mtdda tag           [22mTag tests that failed in the last reference test run
  [1mtdda config        [22mShow or edit TDDA configuration

  [1mtdda version       [22mPrint the TDDA version number
  [1mtdda help          [22mPrint this help
  [1mtdda help COMMAND  [22mPrint help on COMMAND (e.g. discover, verify)

  [1mtdda test          [22mRun the tdda library’s tests.

OPTIONS

  [1m‐[22mv, [1m‐‐version       [22mPrint version number (same as tdda version)
  [1m‐h[22m, [1m‐?[22m, [1m‐‐help      [22mPrint this help
